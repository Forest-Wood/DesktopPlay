# DesktopPet v0.5.4

## 新功能

- 新增 DeepSeek Harness（DSH）完成提醒：只读监听 Windows 本机 v4 普通 JSONL 和 Zstandard 会话日志，仅在主会话明确成功完成后提示，排除取消、失败、子代理和继承历史。支持选择目录、恢复默认与查看监听状态；启动、隐藏和重新开启不补发历史。
- “桌宠与陪伴 → 气泡与提示”提供统一编辑器。小鲸鱼、原版 GPT、白龙分别配置全部气泡的标题、配套短句、显示与悬浮时间、颜色、字体、字号和背景透明度；支持分类覆盖、恢复默认、保留草稿与实际渲染预览。自定义 GPT 图片沿用原版档案。
- “对话完成提醒”集中管理 Codex、ChatGPT Work、DSH 的独立开关及监听状态。每个桌宠 × 来源分别保存文案、气泡、音效、音量和音频文件，支持仅气泡、仅声音或同时开启；完成音效默认关闭，提供内置轻提示音、试听和 MP3/WAV/OGG 导入。
- 同源密集完成合并，跨来源依次提示；拖拽和角色确认期间延后，展示时使用当前桌宠。隐藏会清空队列并停止声音，重新显示不补发，不切换角色或抢焦点。
- 所有桌宠均可显示余额、每日预算和软件更新提醒；金额阈值仍按账户设置，金额、额度、版本和错误状态由系统生成。完成与余额提醒优先于更新。

## 升级与下载

- v0.5.3 可在“关于 → 版本”检查、下载并重启更新。
- v0.5.2 及更早版本可直接手动覆盖升级到本版：从托盘退出旧程序；安装版运行 Setup 并选择原目录，免安装版替换旧 EXE 并保持原位置和原文件名。无需卸载，不要删除 `%APPDATA%\DesktopPlay`。
- 自动迁移旧全局气泡时间、短句、自定义完成文案及共享开关；保留账户、密钥、记录、素材和位置。新设置不保证可被旧版程序降级读取。
- `DesktopPet-0.5.4-Setup-x64.exe`：Windows 10/11 x64 安装版。
- `DesktopPet-0.5.4-Portable-x64.exe`：Windows x64 免安装版。
- `SHA256SUMS.txt`：两个 EXE 的 SHA-256 校验记录；`latest.yml` 和 NSIS blockmap 用于软件内更新。

DSH 首版仅支持本机已识别的 v4，不包含 WSL／远程接入；不读取认证或保存对话正文。真实账户／DSH／Work 端到端与真实用户数据覆盖升级尚未实测，既有本机原生鼠标测试间歇失败继续保留。验证及发布结果见 [T010](../tasks/T010-persona-notifications.md) 与 [T011](../tasks/T011-release-v054.md)。

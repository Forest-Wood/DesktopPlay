# DesktopPet v0.5.3

- 新增安装版与免安装版的软件内更新：自动检查，用户点击下载，再点击“重启并更新”；普通退出不会安装。
- “关于 → 版本”提供版本、发行说明、检查时间、进度、取消和重试；默认启动 30 秒后及每 6 小时检查，可关闭。托盘提供更新入口。
- 每个新版最多提示一次气泡，完成和余额提醒优先，不抢焦点，隐藏时不补弹。
- 重启前提示未保存设置；等待保存任务完成，与卸载互斥。
- 安装版使用 NSIS 覆盖升级；免安装版保持原文件名和位置，校验 SHA-256 后由隐藏助手备份替换，启动失败恢复旧程序。保留设置、密钥、消费记录、素材、位置及开机启动路径。
- 发布流程先上传并核实草稿 Release 的两个 EXE、SHA256SUMS、latest.yml 和 NSIS blockmap，再正式发布。
- 兼容 Windows 短路径目录，通过文件身份验证合法别名，同时继续拒绝符号链接和 junction。

v0.5.2 及更早版本没有更新器，需要先手动覆盖升级到 v0.5.3 一次，无需卸载或删除数据。开发／演示模式不执行真实更新；首版整包下载，不承诺断点续传。

功能验证与限制见 [T008](../tasks/T008-in-app-update.md)，本次发布、CI 与五资源核实见 [T009](../tasks/T009-release-v053.md)。用户已授权发布；实际发布结果以 T009 记录和正式 Release 为准。

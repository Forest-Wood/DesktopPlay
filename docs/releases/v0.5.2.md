# DesktopPet v0.5.2

新增 Codex 重置卡展示，以及使用当前桌宠角色文案的 Codex／ChatGPT Work 结束提醒。

## 重置卡与排版

- GPT 气泡显示可用重置卡总张数和最近已知截止日期；设置页列出接口提供的到期明细、完整时间和时区。
- 总数以接口返回值为准，区分零张、未提供、无到期限制、部分明细及过期缓存；刷新失败保留最近有效数据。本版仅展示，不兑换重置卡。
- 摘要上方增加 12 DIP 留白并去掉横线，原版 GPT／白龙的完整倒计时、百分比和重置卡摘要保持可读。

## 角色化结束提醒

- “提醒与记录 → GPT 完成提醒”可开关提醒，分别编辑小鲸鱼、原版 GPT、白龙的纯文本，支持恢复默认、跨页草稿及保存重启；自定义 GPT 图片沿用原版 GPT 文案。
- 所有角色均可提醒，不切角色、不抢焦点；隐藏桌宠时丢弃，拖拽或角色确认期间延后合并，沿用已有气泡显示和悬浮时间。
- 本机 Codex 通过保存的会话事件和桌面分页历史识别成功完成，过滤失败、取消、子代理及内部来源；兼容 WAL、历史跳过、日志半行、截断、等长覆写、重命名和监听恢复。
- ChatGPT Work 通过 Windows 桌面原生结束通知独立监听。请在 ChatGPT 桌面设置开启回合结束通知，前后台都需提醒时选“始终”（Always）。按本版确认的行为，**Work 失败或中止也会提醒**；该例外不适用于 Codex。应用关闭或抑制的原生通知不会被推测补发。
- 只处理必要的状态、标识和时间，不保存对话正文或原生通知的账户／用户标识，不改写客户端配置或认证。

## 下载与兼容性

- `DesktopPet-0.5.2-Setup-x64.exe`：Windows 10/11 x64 安装版。
- `DesktopPet-0.5.2-Portable-x64.exe`：Windows x64 免安装版。
- `SHA256SUMS.txt`：两个 EXE 的 SHA-256 校验记录。

继续使用既有 appId 与 `%APPDATA%\DesktopPlay` 数据目录，旧配置自动补齐新增设置。正式附件由版本标签触发的 Release 工作流生成；发布过程及校验结果见 [T007](../tasks/T007-release-v052.md)。

## 验证范围

本阶段功能已通过 156 项本地单测、完整 12 项隔离 Electron 检查及 PR #3 CI；发布版本将另外记录 CI 和打包结果。真实 Work 通知格式已核对，更新后真实成功／失败／中止的桌宠端到端试用、真实额度账户及真实安装卸载仍未验证。独立安装版日志路径仅有模拟覆盖；远程、WSL 和未保存受支持事件的客户端不在覆盖范围。

# DesktopPet v0.5.1

气泡默认 3 秒自动收起，新增可保存的显示和悬浮延长时间，修复 GPT 每周倒计时换行，并将设置页面统一为白色。

## 气泡时间设置

- “应用偏好 → 桌面行为”新增“气泡显示时间”（1–60 秒，默认 3 秒）和“悬浮延长时间”（0–60 秒，默认 0 秒／关闭）。点击“保存设置”生效，重启后保留。旧版本配置自动补齐默认值，继续保留既有设置。
- 点击桌宠或翻页重新开始显示计时，自动刷新账户状态不延长显示。悬浮延长关闭时，鼠标位置不影响收起时间。
- 开启悬浮延长后，鼠标悬停气泡时保持显示；移开后按延长时间计时，再次移入会暂停收起。保存新的时间设置会应用到当前气泡。切换角色确认页继续等待用户选择。

![气泡时间设置](../previews/v0.5.1/bubble-settings.png)

## 额度排版与白色页面

- GPT 原版与白龙的紧凑额度气泡采用更小的倒计时字号、较窄的列间距和单行排版，完整显示“6天 23小时 59分钟后重置”等文字；每周继续在左、实际提供的 5H 在右。
- 设置页背景、导航、面板及底部保存栏为白色，移除背景渐变。Windows 深色模式下同样使用白色页面和浅色控件；原生设置窗口底色也同步为白色。

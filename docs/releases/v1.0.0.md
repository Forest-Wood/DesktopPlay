# DesktopPet v1.0.0

- 新增 ChatGPT Work、Codex 和 DeepSeek Harness 的提问与审批提醒，支持 Codex 桌面、独立 CLI 和 IDE 的本机 hook 接入。
- 等待回应和回答完成气泡持续展示，点击正文或现有关闭控件后收起并继续下一条；等待提醒优先，悬停、拖动和切换造型不会误清除。隐藏桌宠或退出软件时清空提醒，重新显示不补发历史。
- 三个桌宠分别控制陪伴短句的候选、每轮数量与随机／顺序模式。每轮可展示 0–20 条，0 关闭短句页；随机同轮不重复，顺序接续已展示位置，候选不足时提示并拒绝保存。
- 三个桌宠分别保存等待文案和外观，短句选择、数量与模式支持草稿及重启恢复；旧配置自动补齐默认值，自定义 GPT 继续共用原版档案。

升级说明：v0.5.3 及以上可在“关于 → 版本”检查更新；更早版本可退出旧程序后直接覆盖升级，无需卸载或删除用户数据。

Codex 等待提醒默认关闭，需在设置中启用接入并保存，再在原客户端完成 hook 信任；不兼容版本会显示明确状态。ChatGPT Work 需开启原生通知；DSH 目前支持 Windows 本机 v4 日志。

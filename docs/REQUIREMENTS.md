## R001：默认气泡显示时间

行为：点击桌宠或翻页后，默认显示 3 秒并自动收起，再次点击从用量页打开。普通账户状态刷新不重置计时。关闭悬浮延长时，鼠标停留或移开不改变收起时间。

验收：在隔离测试中验证小鲸鱼、GPT 原版与白龙；默认配置下计时 2999ms 时可见，达到 3000ms 时隐藏；翻页重新计时，状态广播不延长显示。

## R002：可保存的气泡时间选项

行为：在“应用偏好 → 桌面行为”提供显示时间和悬浮延长时间，按“保存设置”提交并在重启后保留。实现采用整数秒：显示时间 1–60 秒，默认 3 秒；悬浮延长 0–60 秒，默认 0／关闭。启用后悬停保留气泡，移开后按延长时间收起，再次进入暂停收起。角色切换确认页等待用户选择。

验收：切页保留未保存草稿，保存前运行状态不变；保存与重启后取值一致；旧配置补齐默认值；主进程拒绝非法时间且保留原设置；可控时钟验证自定义显示、移开延迟、再次悬停及关闭延长。

变更说明：2026-10-15，用户在默认 3 秒需求后补充两项时间可配置，固定时长因此改为默认值；范围和悬浮语义为本轮实现决定，验证以本节及 R001 为准。

## Codex 桌面兼容修复（2026-10-19）

此前收到桌面 Work 漏提醒反馈后，新增了 Codex 分页历史路径。用户现已确认该补充对 Codex 有效，但它不能代表 ChatGPT Work 的独立 durable 来源。`CodexCompletionHistory` 使用 Node 内置 SQLite，以 `readOnly` 和 `query_only` 查询轮次标识、完成状态／时间及来源；不查询正文表，不改客户端配置、凭据或真实会话文件。没有创建真实推理来做测试，诊断信息不作为 fixture。

每轮只读连接均关闭；数据库缺失时保持旧文件路径，有数据库但锁定或结构不兼容时明确提示并重试，文件路径继续。SQLite 与文件统一去重，数据库另有每会话时间水位，避免共享缓存淘汰后重放。过滤子代理、内部来源、自动化、失败和取消。

数据库时间只有秒精度，以检测时间投递；显示桌宠时同步快照已有终态，避免快速隐藏／显示后补弹。启动与重新开启监听同样建立快照；兼容 WAL 中已提交的更新及没有 sessions 目录的分页历史。IPC、角色文案和设置格式不变。

参考：[Codex 分页历史投影](https://github.com/openai/codex/blob/main/codex-rs/thread-store/src/local/thread_history_materialization.rs)、[Node SQLite 只读接口](https://nodejs.org/download/release/v24.8.0/docs/api/sqlite.html)。只针对实际表结构查询所需字段；将来不兼容结构会提示异常，不承诺所有未来版本自动兼容。

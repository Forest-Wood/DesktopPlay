## 目标与范围

建立前端重设计的视觉 token、纯 DOM 通用组件和 6 项导航路由骨架，将现有设置子页按 [UI_REDESIGN.md](../UI_REDESIGN.md#41-新旧映射) 挂载到新分类下，并引入导航草稿圆点与底部“放弃修改”能力。本任务不重写各业务子页内部排版（留待 T036–T040 逐页迁移）。

### 实现

- `tokens.css` 集中维护工作台、状态、人设舞台与出厂气泡色。设置、气泡及额度样式从中引用颜色。
- `src/renderer/ui/` 提供九个无状态 DOM 工厂，首页用 `card` 承载快捷入口。
- `settings/router.ts` 负责六项导航、页面记忆、焦点管理以及 `tab`／`tabpanel` 语义。首页默认打开，当前阶段提供账户、提醒和更新快捷入口，完整总览见 T036。
- 保存栏按待保存的字段计数，分类及子页标签显示琥珀色圆点。保存提交修改过的字段，短句库与展示配置一起提交以保留选择和播放规则。“放弃修改”取最近同步的设置，保留即时生效的角色、造型等操作。
- Electron 用例共用按 section id 进入子页的辅助函数。用例覆盖键盘导航、15 个原有页面入口、来自其他窗口的设置更新、跨页草稿恢复及两个尺寸。

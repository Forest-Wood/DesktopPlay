## 目标、范围与决定

安装版与免安装版均按“自动检查 → 点击下载 → 点击重启更新”，沿用 appId 和数据目录。默认每次启动 30 秒后检查、运行中每 6 小时；手动检查不受周期限制，开关保存后生效。只接收固定仓库正式新版，不降级、不预发布；开发／演示不执行更新。

扩展共享设置／状态、四个受限 IPC、preload、设置与桌宠、演示接口；openSettings 可选 version，旧调用兼容。更新地址与目标路径只由主进程确定。重启前处理草稿并排空保存；更新与卸载互斥，不复用卸载删除流程。版本统一为本地候选 0.5.3；旧 0.5.2 覆盖升级一次以获得更新器，无需卸载／删数据。

NSIS 使用官方整包更新，关闭自动下载、普通退出安装和差分。免安装下载同 Release 的 EXE／SHA256SUMS，完整验证缓存才复用；安装前再次计算摘要。管理器检查重解析路径、精确 PID／创建时间／祖先启动器，原目录暂存，助手 ready 后才退出。助手等待两个源进程、原子备份替换，健康回执后清备份，明确启动失败恢复；仍运行但没有回执时保留备份，不替换运行文件或强杀进程。助手最多等待来源进程 120 秒、健康回报 60 秒，权限／文件占用／变化均保留可恢复文件。

每版提示标记保存到独立更新状态文件，跨重启及安装类型保留，撤回较新 Release 后也不重复旧提示。手动发现视为已看到；自动检查不抢焦点，隐藏时丢弃不补弹，现有完成／余额气泡优先，拖拽与角色确认延后。

发布先建立草稿，上传两个 EXE、SHA256SUMS、latest.yml、NSIS blockmap，核对文件名／版本／大小／摘要及上传状态后才公开。正式发布步骤未执行；PR 模板已经覆盖需求、验证、迁移和未完成事项，保留有效内容。

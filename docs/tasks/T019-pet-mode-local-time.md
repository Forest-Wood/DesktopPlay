## 实现与决定

1. 版本规则改为用户决定 major、新功能统一 minor、优化 patch，覆盖桌宠数量不参与分类；保留现有显式发布脚本及历史发布计划。产品版本保持 1.0.1。
2. 新增全局 petMode，默认 full。气泡顶部、设置角色页和右键／托盘菜单可切换；main 校验并持久化。简洁模式过滤普通页、余额预算和更新气泡，关闭普通点击声，保留完成／问题／审批及原配置；后台服务继续运行。
3. DeepSeek 新记录按电脑时区和日期统计，Account 与 DaySummary 保存 timeZone／segmentId；旧记录无新字段，保留原金额及北京时间标签。日分段联合键与预算去重键一致；新时区、切回旧时区、观察到时区往返但无成功余额请求都重新建基线。夏令时不额外切分同一当地日。保留最近 365 条日分段；不保证旧二进制可降级读取新字段。
4. 独立的 deepseek-time 模块处理电脑时区格式、官方时段判断、窗口转换、2026 假期和未知年份提示。设置余额页／记录页展示当前峰谷，不拆分历史金额；打开、切页、恢复显示和每分钟更新。
5. 设置草稿保留；来自气泡／菜单的模式变动同步未单独编辑的模式字段。简洁 GPT 仅显示额度窗口与剩余值，隐藏套餐、重置倒计时与重置卡。
